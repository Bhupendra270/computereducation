Computer Software

कंप्यूटर सॉफ्टवेयर

1. Fundamentals / मूल बातें

Software is a collection of programs and instructions that tell computer hardware what to do. Unlike hardware, software is not a physical component. Operating systems, applications, utilities, drivers, and programming tools are examples of software.

System software helps operate and manage the computer itself. An operating system controls resources such as memory, files, processes, devices, and user accounts. Application software is designed to help users perform specific tasks such as writing documents, browsing websites, editing images, creating presentations, or calculating data.

Software is created by programmers using programming languages. Source code is translated or interpreted so that the computer can execute the required instructions.

Software must also be updated and maintained. Updates may improve features, fix bugs, improve performance, or correct security weaknesses. Users should install software from trustworthy sources and understand the permissions requested by applications.

Identify the input, the operation being performed, the expected output, and the way the result can be checked.
