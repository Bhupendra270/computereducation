1. Introduction — कंप्यूटर का परिचय

आज का युग technology और digital information का युग है। हमारे आसपास लगभग हर क्षेत्र में computers और digital devices का उपयोग हो रहा है। स्कूल में पढ़ाई, office में काम, bank में transaction, hospital में patient records, railway में ticket booking, दुकान में billing, government office में records और घर में entertainment जैसे अनेक कार्य computer की सहायता से किए जाते हैं। इसलिए computer की basic knowledge आज केवल computer students के लिए ही नहीं, बल्कि लगभग हर व्यक्ति के लिए उपयोगी है।

Computer को समझने के लिए सबसे पहले यह समझना जरूरी है कि computer वास्तव में क्या करता है। Computer स्वयं से कोई सामान्य मानवीय निर्णय लेने वाली मशीन नहीं है। यह user द्वारा दिए गए instructions और data के आधार पर काम करता है। User input देता है, computer उस input को process करता है और फिर result देता है।

सरल उदाहरण:
यदि आप calculator में 25 + 35 enter करते हैं, तो 25 और 35 input हैं। Computer calculation करता है और 60 result के रूप में दिखाता है।

2. Computer क्या है?

Computer एक electronic programmable device है जो data को input के रूप में प्राप्त करता है, दिए गए instructions के अनुसार उस data को process करता है, result को output के रूप में प्रस्तुत करता है और आवश्यकता पड़ने पर information को store करता है।

सरल भाषा में कहा जाए तो computer एक ऐसी electronic machine है जो हमारे द्वारा दिए गए instructions के अनुसार बहुत तेज गति से विभिन्न प्रकार के tasks perform कर सकती है।

Computer शब्द का संबंध मूल रूप से calculation अर्थात गणना से जुड़ा है। प्रारंभिक computing machines मुख्य रूप से mathematical calculations के लिए बनाई गई थीं, लेकिन आधुनिक computers केवल calculation तक सीमित नहीं हैं। आज computer text, images, audio, video, communication, programming, databases और internet services जैसे अनेक प्रकार के digital tasks को handle कर सकते हैं।

3. Computer की आवश्यकता क्यों है?

Computer का सबसे बड़ा लाभ यह है कि यह repetitive और complex tasks को तेज, संगठित और reliable तरीके से करने में सहायता करता है। यदि किसी organization को हजारों customers के records maintain करने हों, तो manually records maintain करना बहुत समय लेने वाला और कठिन हो सकता है। Computer database के माध्यम से इन records को व्यवस्थित रखने, खोजने और update करने में सहायता करता है।

इसी प्रकार school में students के marks, attendance और fee records computer में maintain किए जा सकते हैं। Business में sales और expenses record किए जा सकते हैं। Hospital में appointments और reports manage की जा सकती हैं।

4. Computer की Basic Working

Computer की working को समझने के लिए चार basic stages को समझना बहुत जरूरी है: Input, Processing, Output और Storage।

4.1 Input

Input वह data या instruction है जो user computer को देता है। Keyboard, mouse, microphone, scanner और touchscreen input देने के सामान्य माध्यम हैं।

उदाहरण के लिए जब आप keyboard पर अपना नाम type करते हैं, तो keyboard द्वारा दिया गया text computer के लिए input है। जब आप mouse से किसी icon पर click करते हैं, तो mouse का action भी input है।

4.2 Processing

Processing का अर्थ है input data पर आवश्यक operations करना। Computer का processor instructions को execute करने और calculations तथा logical operations में महत्वपूर्ण भूमिका निभाता है।

उदाहरण के लिए यदि user 100 और 200 numbers enter करता है और addition operation select करता है, तो computer इन values को process करके 300 result तैयार करेगा।

4.3 Output

Processing के बाद प्राप्त result को output कहते हैं। Monitor, printer, speaker और projector output devices के उदाहरण हैं।

4.4 Storage

यदि information को future में फिर से उपयोग करना हो तो उसे storage में save किया जा सकता है। Hard Disk, SSD, USB flash drive और memory card इसके उदाहरण हैं।

एक पूरा उदाहरण:
Student keyboard से marks enter करता है → Computer marks को process करता है → Monitor पर total और percentage दिखाई जाती है → Result को storage में save किया जाता है।

5. Data क्या है?

Data का अर्थ raw facts और figures से है। Data अपने आप में उपयोगी हो सकता है, लेकिन अक्सर meaningful information प्राप्त करने के लिए data को process करना पड़ता है।

Student का नाम, roll number, marks, age और attendance percentage अलग-अलग data items हो सकते हैं। जब इन सभी values को एक साथ analyze करके student का final result बनाया जाता है, तो processed information प्राप्त होती है।

6. Information क्या है?

जब raw data को process, organize या analyze करके meaningful result प्राप्त होता है, तो उसे information कहा जा सकता है।

उदाहरण के लिए यदि पांच subjects के marks को जोड़कर total marks, percentage और grade calculate किया जाता है, तो यह information है। Information decision making में अधिक उपयोगी होती है क्योंकि यह raw data की तुलना में अधिक meaningful होती है।

8. Computer की प्रमुख विशेषताएँ

8.1 High Speed — तेज गति

Computer बहुत तेजी से calculations और instructions execute कर सकता है। जहाँ किसी व्यक्ति को हजारों calculations manually करने में बहुत समय लग सकता है, computer वही काम बहुत कम समय में कर सकता है।

8.2 Accuracy — शुद्धता

Computer सही instructions और सही input मिलने पर अत्यधिक accurate results दे सकता है। लेकिन यह याद रखना जरूरी है कि computer स्वयं input की हर गलती को समझकर सुधार नहीं देता। यदि user गलत data enter करता है, तो result भी गलत हो सकता है।

महत्वपूर्ण: Computer की speed और accuracy का लाभ तभी मिलता है जब input और instructions सही हों। इसे समझने के लिए "Garbage In, Garbage Out" concept महत्वपूर्ण है।

8.3 Storage Capacity

Modern computers बड़ी मात्रा में digital data store कर सकते हैं। Documents, photos, videos, presentations और अन्य files को storage devices में रखा जा सकता है।

8.4 Automation

Computer instructions मिलने के बाद कई tasks automatically perform कर सकता है। उदाहरण के लिए spreadsheet में formula लगाने के बाद हजारों rows की calculations automatically हो सकती हैं।

8.5 Reliability

Computer repetitive tasks को लगातार perform कर सकता है। एक properly maintained system एक ही तरह के काम को बार-बार करने में consistent results दे सकता है।

8.6 Versatility

Computer की versatility का अर्थ है कि एक ही machine का उपयोग अलग-अलग tasks के लिए किया जा सकता है। आप उसी computer पर document बना सकते हैं, internet चला सकते हैं, programming कर सकते हैं, video देख सकते हैं और presentation बना सकते हैं।

9. Computer की सीमाएँ

Computer के अनेक advantages हैं, लेकिन इसकी limitations भी हैं। Computer मानवीय instructions और programmed logic पर निर्भर करता है। सामान्य computer को काम करने के लिए hardware, software, power और उचित instructions की आवश्यकता होती है।

Computer emotions, सामान्य human judgment और वास्तविक दुनिया की context को मनुष्य की तरह naturally समझ नहीं सकता। आधुनिक AI systems कई advanced tasks कर सकते हैं, फिर भी उनका behavior underlying software, models, data और instructions पर निर्भर रहता है।

11. Software क्या है?

Software computer programs और instructions का collection होता है। Software hardware को बताता है कि कौन सा काम कैसे perform करना है। Software को physical object की तरह हाथ से नहीं छुआ जा सकता।

Microsoft Windows, Linux, web browsers, text editors, media players और office applications software के examples हैं।

12. Hardware और Software का संबंध

Hardware और software एक-दूसरे के बिना सामान्य computer system में उपयोगी तरीके से काम नहीं कर सकते। Hardware physical infrastructure प्रदान करता है और software उस hardware को instructions देता है।

13. Computer के प्रमुख प्रकार

Desktop Computer

Desktop एक ऐसा computer है जिसे सामान्यतः desk या fixed workplace पर उपयोग किया जाता है। इसमें monitor, keyboard, mouse और system unit जैसे अलग-अलग components हो सकते हैं।

Laptop

Laptop एक portable computer है जिसमें screen, keyboard, touchpad, battery और computing components compact design में integrated होते हैं। इसे अलग-अलग locations पर ले जाकर उपयोग किया जा सकता है।

19. Computer System के मुख्य भाग — Detailed Explanation

Computer system को अच्छी तरह समझने के लिए उसके अलग-अलग components को समझना आवश्यक है। एक computer केवल monitor या CPU cabinet का नाम नहीं है। वास्तव में computer system hardware, software, data, users और procedures के मिलकर काम करने से एक complete system बनता है। प्रत्येक component की अपनी भूमिका होती है और सभी components एक-दूसरे पर निर्भर होते हैं।

19.1 Central Processing Unit — CPU

CPU का पूरा नाम Central Processing Unit है। इसे सामान्य रूप से computer का processing center कहा जाता है। CPU program instructions को execute करता है और calculations तथा logical operations में महत्वपूर्ण भूमिका निभाता है। जब कोई application कोई task perform करती है, तो processor उस task के instructions को execute करने में सहायता करता है।

CPU के अंदर कई महत्वपूर्ण functional units होती हैं। इनमें Arithmetic Logic Unit, Control Unit और registers जैसी components शामिल हो सकती हैं। Arithmetic Logic Unit arithmetic तथा logical operations perform करती है। Control Unit instructions के execution को coordinate करती है। Registers बहुत तेज internal storage locations होती हैं जिनका उपयोग processor temporary values और instructions के साथ काम करते समय करता है।

उदाहरण:
यदि calculator application में 250 + 350 calculate किया जाता है, तो user द्वारा दिए गए numbers और operation को software handle करता है और processor आवश्यक computation करने में सहायता करता है। Result के रूप में 600 दिखाई देता है।

19.2 Memory — RAM और ROM

Computer memory का उपयोग instructions और data को रखने के लिए किया जाता है। RAM का पूरा नाम Random Access Memory है। RAM सामान्यतः temporary working memory के रूप में उपयोग होती है। जब कोई application चलती है, तो operating system और applications को काम करने के लिए RAM की आवश्यकता होती है।

RAM volatile memory है। इसका अर्थ है कि सामान्य परिस्थितियों में power बंद होने पर RAM में मौजूद working data सुरक्षित नहीं रहता। इसलिए महत्वपूर्ण documents को केवल RAM में रखना पर्याप्त नहीं है। उन्हें permanent storage में save करना आवश्यक है।

ROM का पूरा नाम Read Only Memory है। ROM या firmware memory में ऐसी instructions हो सकती हैं जो computer hardware को प्रारंभ करने या basic functions में सहायता करती हैं। Modern systems में firmware implementation अलग-अलग प्रकार की non-volatile memory तकनीकों का उपयोग कर सकती है।

19.3 Motherboard

Motherboard computer का मुख्य circuit board होता है। यह processor, memory, storage, expansion devices और अन्य components को electrical तथा communication connections प्रदान करता है। Motherboard पर अलग-अलग slots, connectors और controller components हो सकते हैं।

यदि motherboard को computer system के एक central platform की तरह समझें, तो यह अलग-अलग hardware components के बीच communication के लिए आवश्यक connections उपलब्ध कराता है। इसलिए motherboard का सही design और compatibility computer system की stability के लिए महत्वपूर्ण है।

20. Input Devices — विस्तार से

Input device वह hardware component है जिसके माध्यम से user computer को data या commands देता है। अलग-अलग tasks के लिए अलग-अलग input devices उपयोग किए जाते हैं। Keyboard text और commands enter करने के लिए सबसे सामान्य devices में से एक है। Mouse graphical interface में pointer को control करने के लिए उपयोग किया जाता है।

20.1 Keyboard

Keyboard में alphabetic keys, numeric keys, function keys, control keys और navigation keys जैसी अलग-अलग keys होती हैं। सामान्य typing के लिए alphabetic keys उपयोग होती हैं। Numbers enter करने के लिए numeric keys उपयोग की जाती हैं। Enter, Backspace, Delete, Shift, Ctrl, Alt और Tab जैसी keys अलग-अलग commands और editing operations में सहायता करती हैं।

Keyboard सीखते समय केवल keys के नाम याद करना पर्याप्त नहीं है। Student को typing, editing, shortcut keys और correct finger placement का practical अभ्यास करना चाहिए। धीरे-धीरे typing speed बढ़ाने से productivity बेहतर होती है।

20.2 Mouse

Mouse graphical user interface के साथ interaction के लिए उपयोग किया जाता है। Mouse से pointer को move किया जा सकता है, single click, double click, right click और drag-and-drop operations किए जा सकते हैं।

Single click सामान्यतः किसी item को select करने के लिए उपयोग किया जाता है। Double click कई graphical interfaces में file या application खोलने के लिए उपयोग होता है। Right click context menu खोल सकता है। Drag-and-drop से files या objects को एक location से दूसरी location पर move किया जा सकता है।

20.3 Scanner

Scanner physical documents या images को digital form में convert करने में सहायता करता है। इसका उपयोग offices, schools, businesses और अन्य organizations में documents digitize करने के लिए किया जा सकता है।

20.4 Microphone और Webcam

Microphone audio input capture करता है। इसका उपयोग voice recording, online meetings, voice commands और communication में किया जा सकता है। Webcam images और video capture करने के लिए उपयोग होती है। Online classes और video conferences में webcam का व्यापक उपयोग होता है।

21. Output Devices — विस्तार से

Output device computer द्वारा process की गई information को user तक पहुंचाने में सहायता करता है। Output visual, printed या audio form में हो सकता है।

21.1 Monitor

Monitor एक visual output device है। यह text, images, videos, windows और graphical interfaces को screen पर दिखाता है। Monitor की quality को resolution, refresh rate, panel technology, brightness और color reproduction जैसे factors प्रभावित कर सकते हैं।

21.2 Printer

Printer digital document को physical printed form में प्रस्तुत करता है। Inkjet और laser printers सामान्य printer technologies के उदाहरण हैं। Printer चुनते समय print quality, speed, running cost, connectivity और intended use जैसे factors देखे जा सकते हैं।

21.3 Speaker और Headphones

Speakers और headphones audio output प्रदान करते हैं। Music, video, notifications, online classes और communication applications में audio output का उपयोग किया जाता है।

22. Storage Devices — विस्तार से

Storage का उद्देश्य data को लंबे समय तक सुरक्षित रखना है। Computer में documents, photos, videos, applications और अन्य files storage devices में रखी जाती हैं। Storage को broadly internal और external storage के रूप में समझा जा सकता है।

22.1 Hard Disk Drive — HDD

HDD magnetic storage technology का उपयोग करता है। इसमें rotating platters और moving read/write mechanism होते हैं। HDD सामान्यतः large-capacity storage के लिए लंबे समय से उपयोग किया जाता रहा है।

22.2 Solid State Drive — SSD

SSD flash memory आधारित storage technology का उपयोग करता है और इसमें HDD की तरह moving mechanical platters नहीं होते। SSD सामान्यतः fast access और responsive system experience प्रदान कर सकता है। Operating system और frequently used applications के लिए SSD का उपयोग computer को अधिक responsive बना सकता है।

22.3 USB Flash Drive

USB flash drive एक portable storage device है। इसका उपयोग files को एक compatible computer से दूसरे compatible computer में transfer करने के लिए किया जा सकता है। लेकिन unknown या untrusted USB devices को computer में connect करते समय security का ध्यान रखना चाहिए।

23. Software की विस्तृत समझ

Software को केवल applications के रूप में समझना incomplete है। Computer में system software और application software दोनों महत्वपूर्ण हैं। System software hardware और basic computer operations को manage करने में सहायता करता है। Application software user को specific tasks करने देता है।

23.1 Operating System

Operating system computer का fundamental system software है। यह hardware resources को manage करता है और applications को run करने के लिए environment प्रदान करता है। Windows, Linux, macOS, Android और iOS अलग-अलग प्रकार के operating systems के उदाहरण हैं।

Operating system के सामान्य functions में process management, memory management, file management, device management, security और user interface प्रदान करना शामिल है। जब user कोई file open करता है, application launch करता है या printer का उपयोग करता है, तो operating system background में अनेक operations coordinate करता है।

23.2 Application Software

Application software specific user tasks के लिए बनाया जाता है। Word processors documents बनाने में सहायता करते हैं। Spreadsheet applications calculations और data analysis में उपयोगी होती हैं। Presentation applications slides बनाने के लिए उपयोग की जाती हैं। Web browsers websites access करने में सहायता करते हैं।

24. Computer में File और Folder

File digital information का एक organized unit है। Document, image, video, audio और text file अलग-अलग प्रकार की files हो सकती हैं। Folder files को organize करने के लिए उपयोग किया जाता है।

यदि किसी student के computer में hundreds of files हों, तो उन्हें बिना folders के manage करना कठिन हो सकता है। इसलिए subject, project, date या purpose के अनुसार folders बनाना एक अच्छी computer habit है।

25. Computer और Internet में अंतर

Computer और Internet एक ही चीज नहीं हैं। Computer एक computing device या system है, जबकि Internet interconnected networks का global system है जिसके माध्यम से devices और networks communication कर सकते हैं। Computer internet के बिना भी कई local tasks perform कर सकता है। इसी प्रकार internet services access करने के लिए computer के अलावा smartphone, tablet और अन्य devices का उपयोग किया जा सकता है।

26. Computer Security की Basic बातें

Computer का उपयोग करते समय security महत्वपूर्ण है। Strong passwords का उपयोग करना, software को updated रखना, suspicious files और links से सावधान रहना तथा important data का backup रखना basic security practices हैं।

Password किसी दूसरे व्यक्ति के साथ share नहीं करना चाहिए। अलग-अलग important accounts के लिए unique passwords रखना बेहतर practice है। जहाँ उपलब्ध हो वहाँ multi-factor authentication का उपयोग account security को मजबूत कर सकता है।

Unknown email attachments, suspicious websites और unexpected software downloads computer security के लिए risk पैदा कर सकते हैं। किसी भी file या link को खोलने से पहले उसके source और purpose को verify करना चाहिए।

27. Backup क्यों जरूरी है?

Computer में stored data hardware failure, accidental deletion, malware, theft या अन्य कारणों से खो सकता है। इसलिए important documents का backup रखना जरूरी है। Backup का अर्थ important data की अतिरिक्त copy रखना है।

एक practical backup strategy में important files की दूसरी copy external storage या trusted cloud storage में रखी जा सकती है। Backup केवल बनाना ही पर्याप्त नहीं है। समय-समय पर यह check करना भी जरूरी है कि backup वास्तव में restore किया जा सकता है।

28. Troubleshooting की Basic Method

जब computer में कोई समस्या आती है, तो घबराने के बजाय problem को छोटे हिस्सों में divide करना चाहिए। सबसे पहले समस्या को स्पष्ट रूप से identify करें। इसके बाद connections, power, settings, software और input को क्रम से check करें।

  1. समस्या को ध्यान से observe करें।
  2. Error message को पूरा पढ़ें।
  3. Power और physical connections check करें।
  4. Input सही है या नहीं verify करें।
  5. Application या file सही location पर है या नहीं check करें।
  6. एक समय में एक change करें।
  7. Change के बाद result observe करें।
  8. जरूरत होने पर system या application को safely restart करें।

33. Computer में User की भूमिका

Computer powerful machine है, लेकिन user की भूमिका बहुत महत्वपूर्ण रहती है। User data enter करता है, software चुनता है, instructions देता है, results को समझता है और आवश्यकता के अनुसार decisions लेता है। इसलिए computer literacy का अर्थ केवल computer चलाना नहीं बल्कि digital information को सही तरीके से समझना भी है।

उदाहरण के लिए यदि spreadsheet में कोई percentage गलत दिखाई दे रही है, तो user को केवल computer को दोष नहीं देना चाहिए। Formula, input values, cell references और formatting को check करना चाहिए। इसी तरह यदि कोई document नहीं मिल रहा है, तो file name, folder location और search facility का उपयोग करके उसे खोजा जा सकता है।

34. Digital Responsibility

Computer और Internet का उपयोग करते समय digital responsibility रखना आवश्यक है। दूसरों की personal information को बिना अनुमति share नहीं करना चाहिए। किसी दूसरे व्यक्ति के account में unauthorized access का प्रयास नहीं करना चाहिए। Copyrighted material का उपयोग करते समय applicable permissions और rules का ध्यान रखना चाहिए।

Digital communication में भी सावधानी आवश्यक है। Email, messaging और social platforms पर message भेजने से पहले यह देखना चाहिए कि information सही व्यक्ति तक जा रही है या नहीं। Sensitive information को अनावश्यक रूप से public स्थान पर share नहीं करना चाहिए।

36. Lesson 1 Final Understanding

Computer fundamentals को समझने के बाद learner को computer को केवल एक machine के रूप में नहीं बल्कि hardware और software के coordinated system के रूप में देखना चाहिए। Hardware physical components प्रदान करता है, software instructions और functionality प्रदान करता है, जबकि user इन दोनों का उपयोग करके desired task पूरा करता है। Input के माध्यम से data system में आता है, processing के दौरान instructions के अनुसार operations होते हैं, output के माध्यम से result मिलता है और storage future use के लिए information को सुरक्षित रखने में सहायता करता है।

एक अच्छे beginner को definitions याद करने के साथ-साथ यह भी पता होना चाहिए कि किस concept का practical उपयोग कहाँ होता है। यदि student keyboard से data enter करता है, application उस data को process करती है, monitor result दिखाता है और file को SSD पर save किया जाता है, तो वह एक complete computer workflow को समझ रहा है। यही fundamental understanding आगे Operating System, Internet, Microsoft Office, programming और अन्य advanced computer topics सीखने की मजबूत foundation बनाती है।
